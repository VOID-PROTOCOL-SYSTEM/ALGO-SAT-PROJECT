# Memo Archive

Static GitHub Pages site for my marimo notebook exports, themed with `cyberpunk-marimo.css`.

## Layout
```
index.html                  landing page (generated by build.py)
build.py                    edit GROUPS at the top, then run it
assets/cyberpunk-marimo.css your theme (same file you inject into marimo)
assets/site.css             landing-page layout on top of the theme
notebooks/*.html            marimo exports (build.py injects an INDEX/PREV/NEXT widget)
.nojekyll                   tells GitHub Pages not to process files
```

## Adding / updating a notebook
(first, `pip install playwright && playwright install chromium` if you want card previews)
1. Export/save the HTML into `notebooks/`
2. Add it to `GROUPS` in `build.py`
3. `python tools/make_previews.py`  (optional: refreshes card screenshots + headlines)
4. `python build.py`
5. `git add . && git commit -m "update" && git push`

## First-time deploy
1. Create a new repo on GitHub (e.g. `memo-archive`)
2. In this folder: `git init && git add . && git commit -m "init"`
3. `git branch -M main && git remote add origin https://github.com/<you>/memo-archive.git && git push -u origin main`
4. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save
5. Site appears at `https://<you>.github.io/memo-archive/` in a minute or two

## Sleeper mode (v10.4)
Arm any prank from a link so it goes off later. Type `prank` (or run `prank` in the terminal) for a **prank link builder**: pick the prank, pick when it fires, copy the link, send it.
Link format: `index.html#sleeper=panic:idle:90` (a `?sleeper=` query works too); chain several with `;` e.g. `#sleeper=rickroll:click;winupdate:delay:120-300`.
Prank: `any` (random surprise) `panic` `rickroll` `winupdate` `crash[.win|.mac|.linux|.snap]` `dodge` `captcha` `loading` `driver` `gravity[.up]` `dvd` `destruct` `typer`.
Trigger: `random` (1-5 min) / `delay:N` or `delay:A-B` seconds / `idle:N` seconds of no input / `click[:n]` the nth click on a notebook link (that click is swallowed and the prank fires instead) / `scroll:N` percent down the page / `load`.
The link hides itself from the address bar after it loads, is remembered for that tab (so wandering into a notebook and back re-arms it), and fires once per tab session. It waits if an overlay is open or they are typing. Fullscreen pranks (`winupdate`, `crash`) only go fullscreen when the browser allows it; the `click` trigger works best for that.
Disarm: type `disarm` anywhere, run `disarm`, or open the page with `#sleeper=off`. `sleeper list` shows what is armed; `sleeper panic idle 60` arms one by hand. Esc still leaves every prank. Files: `assets/sleeper.js`, `assets/sleeper.css`.
